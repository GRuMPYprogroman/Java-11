### hw_1_java — Калькулятор и последовательности

Два независимых упражнения на базовый синтаксис Java:

- **`calculator/`** — консольный калькулятор (`Calculator.calculate(a, b, op)`), поддерживающий `+`, `-`, `*`, `/` с проверкой деления на ноль и обработкой некорректной операции через исключения. `Main` считывает два числа и операцию из `Scanner`.
- **`sequences/`** — генерация случайного массива чисел (`int`/`double`, перегруженные методы) в заданном диапазоне `[a, b]`, сортировка пузырьком (`sort_bubble`) и вычисление максимума, минимума и среднего значения (`aMax`, `aMin`, `aMean`).

### Hw2 — 3D-вектор

Класс `vector.Vector` — представление вектора в трёхмерном пространстве с операциями:

- длина вектора (`len`);
- скалярное (`scalarMultiplication`) и векторное (`vectorMultiplication`) произведение;
- косинус угла между векторами (`findAngle`);
- сложение и вычитание векторов (`sumVec`, `subtVec`);
- генерация списка случайных векторов (`createVectors`).

`main.main` демонстрирует вычисление длины двух векторов, их скалярного произведения и угла между ними.

### Hw3 — Иерархия транспортных средств

ООП-задание на наследование, абстрактные классы и интерфейсы. Подробное описание архитектуры — в [`Hw3/src/README.md`](Hw3/src/README.md), кратко:

- **`Vehicle`** — абстрактный базовый класс с общими атрибутами (`currSpeed`, `relativeSpeed`, `costPrice`, `maxPassengers`, `envHarm`, `wheelAmount`) и статическим учётом созданных экземпляров каждого подтипа.
- **`Car`, `Plane`, `Bicycle`, `Ship`** — финальные подклассы `Vehicle`, каждый со своей спецификой (например, `Plane` добавляет высоту полёта) и собственным перечислением брендов (`carBrands`, `planeBrands`, `bicycleBrands`, `shipBrands`).
- **`vehicleService<T>`** — обобщённый интерфейс управления транспортом: `startEngine`, `turnRight`/`turnLeft`, `stopVehicle`, `accelerate`/`decelerate`, `deleteInstance`.

К заданию приложена диаграмма иерархии классов — [`vehicle_hierarchy.png`](Hw3/src/vehicle_hierarchy.png).

### hw4 — ObservableStringBuilder

Реализация паттерна **"Наблюдатель"** (Observer) поверх `StringBuilder`:

- `ChangeListener` — функциональный интерфейс с методом `onChange()`.
- `ObservableStringBuilder` — оборачивает `StringBuilder`, хранит список слушателей и уведомляет их (`notifyListeners`) при каждом изменении содержимого (`append`, `insert`, `delete`).
- `Main` подписывает анонимный листенер, который печатает текущее состояние строки после каждой модификации.

### hw5 — Многопоточный мини-банк

Более сложное задание на конкурентное программирование: симуляция банка с несколькими клиентами, обменом валют и переводами между счетами.

- **`Bank`** — хранит курсы валют (`ConcurrentHashMap`), очередь транзакций (`LinkedBlockingQueue`) и пул потоков (`ExecutorService` на 5 потоков + `ScheduledThreadPoolExecutor`, который раз в секунду случайно "колеблет" курсы валют). Операции `exchangeCurrency` и `transferFunds` кладут задачу в очередь и передают её на выполнение внутреннему классу `Cashier` (`Runnable`), который извлекает и исполняет транзакцию в отдельном потоке.
- **`Client`** — баланс клиента по нескольким валютам (`RUB`/`USD`/`EUR`), потокобезопасные `deposit`/`withdraw` через `ReentrantLock`, выброс исключения при нехватке средств.
- **`Observer` / `Logger`** — паттерн "Наблюдатель": `Bank` уведомляет подписанные `Observer`'ы (в т.ч. `Logger`, печатающий события в консоль) об успешных операциях и ошибках.
- **`BankApp`** — точка входа: создаёт банк, логгер и двух клиентов, запускает обмен валюты и перевод средств, ждёт завершения асинхронных операций и останавливает пул потоков (`turnOff`).

### Отбор — Отборочные задачи (C++)

CMake-проект с решениями двух алгоритмических задач, использованных на отборе (не относится к курсу Java):

- **`task_1.cpp`** — находит **3-е по величине уникальное число** во введённой последовательности: числа считываются в `std::vector`, уникальные значения собираются в `std::set<int, std::greater<int>>` (отсортированы по убыванию), если уникальных элементов меньше, чем введено — выбрасывается исключение; ошибки ввода перехватываются через `std::ios_base::failure`.
- **`task_2.cpp`** — задача "**ближайшие подходящие кафе**": по координатам пользователя и списку кафе (координаты + рейтинг) отбирает кафе с рейтингом не ниже 4 и находит `N` ближайших к пользователю (через `std::shared_ptr`/`std::unique_ptr` и сортировку по расстоянию).

Сборка (локально, из `Отбор/`):

```bash
cmake -S . -B build
cmake --build build
```

## Технологии

- **Java** — базовый синтаксис, ООП (абстрактные классы, интерфейсы, enum), паттерн "Наблюдатель", многопоточность (`java.util.concurrent`: `ExecutorService`, `ScheduledThreadPoolExecutor`, `ConcurrentHashMap`, `ReentrantLock`).
- **C++17** — STL-контейнеры (`vector`, `set`), умные указатели (`shared_ptr`, `unique_ptr`), обработка исключений, сборка через CMake/Ninja.

## Как запустить Java-примеры

Каждое задание — независимый набор `.java`-файлов без единой системы сборки; собирать и запускать нужно из соответствующей папки, например:

```bash
cd hw_1_java/calculator
javac Main.java Calculator.java
java calculator.Main
```

```bash
cd hw5
javac *.java
java BankApp
```
